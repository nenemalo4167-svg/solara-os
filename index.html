ISO Neural Assistant

La IA trabaja por vos, mientras vos seguís trabajando.

Un asistente de IA diseñado para interactuar con el sistema y aplicaciones, convirtiendo instrucciones en acciones concretas.

Windows 10+ Linux

Acciones

Abrir apps, gestionar ventanas, navegar interfaces, automatizar tareas.

Multiaplicación

Trabaja con varias apps, genera y modifica contenido.

Recursos

Usa CPU, GPU y NPU según la tarea, en segundo plano.

Funciona como otro usuario operando la PC, pero con permisos controlados.

Privacidad bajo control del usuario

El Neural Assistant tiene integración profunda, pero el acceso a archivos personales está restringido por defecto. El usuario autoriza carpetas, apps o tareas específicas.

Productividad en segundo plano

Neural Assistant → trabajando en SketchUp
Usuario → navegando, programando, etc.
El Kusai 200 distribuye recursos entre CPU, GPU y NPU para ambas actividades simultáneas.
